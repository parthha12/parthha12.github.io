Product

Three things. That’s the whole app.

Quick capture

Type in the main field or press ⌘N. Optional screenshot with ⌘⇧N.

Natural language when

“Remind me tomorrow at 9.” “When I open Slack.” Save — Jot stores the trigger with your note.

Resurface

When time or app matches, one calm overlay card appears. Dismiss, snooze, or done.

Shortcuts

Stay in flow

  • ⌘⇧J — Toggle the app
  • ⌘N — Quick capture window
  • ⌘⇧N — Screenshot + capture
  • ⌘P — Reminders library
  • ↵ — Save from the NLP field

Download J.O.T. Reminders

macOS only. The public build is not yet notarized with an Apple Developer ID, so you will need one Terminal command after installing.

Install (about 60 seconds)

  1. Download the latest JOT-Reminders-*.dmg using the button below.
  2. Open the DMG and drag J.O.T. Reminders into Applications.
  3. In Terminal, run: 
    xattr -cr "/Applications/J.O.T. Reminders.app"
  4. Open J.O.T. Reminders from Applications. Press ⌘⇧J to toggle, then type a reminder and click Save reminder.

macOS may say the app is from an unidentified developer or is damaged. The Terminal step clears that. No Terminal? Right-click the app → Open → Open, or System Settings → Privacy & Security → Open Anyway.

Grant Automation when asked (frontmost app for “when I open…” reminders). Screen Recording is optional for this build.
